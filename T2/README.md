# ჰიბრიდული დაშიფვრის სისტემა (RSA + AES)

## პროცესის აღწერა

1. **ბობი აგენერირებს RSA გასაღებების წყვილს**:
- private.pem - პირადი გასაღები (უსაფრთხო ადგილას ინახება)
- public.pem - საჯარო გასაღები (ელისს გადაეცემა)

2. **ელისი აშიფრავს შეტყობინებას**:
- აგენერირებს შემთხვევით AES-256 გასაღებს და IV-ს
- alice_message.txt ფაილს შიფრავს AES-256-ით (CBC რეჟიმი)
- AES გასაღებს შიფრავს ბობის RSA საჯარო გასაღებით
- აგენერირებს encrypted_file.bin და aes_key_encrypted.bin ფაილებს

3. **ბობი განშიფრავს შეტყობინებას**:
- RSA პირადი გასაღებით განშიფრავს AES გასაღებს
- განშიფრული AES გასაღებით განშიფრავს შეტყობინებას
- ამოწმებს SHA-256 ჰეშს მთლიანობის დასადასტურებლად

## RSA vs AES შედარება

| კრიტერიუმი             | RSA                                          | AES                                       |
|------------------------|----------------------------------------------|-------------------------------------------|
| სიჩქარე                | ნელი (ასიმეტრიული)                           | სწრაფი (სიმეტრიული)                       |
| გამოყენების არეალი     | მცირე მონაცემებისთვის (გასაღებების გაცვლა)   | დიდი მონაცემებისთვის (ფაილების დაშიფვრა)  |
| უსაფრთხოება            | დამოკიდებულია გასაღების ზომაზე (2048 ბიტი+)  | დამოკიდებულია გასაღების ზომაზე (256 ბიტი) |
| პრაქტიკული გამოყენება  | სერვერებს შორის უსაფრთხო კავშირისთვის        | მონაცემთა დაშიფვრისთვის დისკზე            |

## რატომ ჰიბრიდული სისტემა?

ჰიბრიდული სისტემა აერთიანებს ორივე ალგორითმის უპირატესობებს:
- RSA უზრუნველყოფს უსაფრთხო გასაღებების გაცვლას
- AES უზრუნველყოფს დიდი ფაილების სწრაფ და ეფექტურ დაშიფვრას
